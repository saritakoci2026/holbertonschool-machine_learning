# Math - Plotting

This project contains Python scripts for plotting data using NumPy and Matplotlib.

## Task 0: Line Graph

The `0-line.py` script defines a function named `line()` that plots a cubic line graph.

- Uses NumPy to generate values from 0 to 10.
- Displays the graph as a solid red line.
- Sets the x-axis limits from 0 to 10.
- Uses Matplotlib to display the graph.

## Requirements

- Python 3
- NumPy
- Matplotlib
