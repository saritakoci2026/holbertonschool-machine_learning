# Probability

This directory contains Python exercises related to probability and statistical distributions.

## Tasks

### 6. Initialize Normal

Implementation of a `Normal` class that represents a normal distribution.

The class supports:
- Initializing with a list of data.
- Calculating the mean.
- Calculating the standard deviation.
- Initializing with predefined mean and standard deviation.
- Validating input data and standard deviation.
### 8. Normal PDF

Added a `pdf` method to the `Normal` class to calculate the probability density function for a given x-value.
